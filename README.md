# Азбука с Ори

Браузерная игра для ребёнка 5–7 лет: мудрый инопланетянин Ори обучает русскому алфавиту и чтению четырёх инопланетных детей — Лулу, Бипа, Тума и Ниму.

Игра находится в одном файле `index.html`, не требует библиотек и сборки. Открывается на компьютере, планшете и телефоне. После скачивания голоса и первого открытия по HTTP(S) работает без интернета.

## Что внутри

- **45 уроков:** отдельный урок для каждой из 33 букв и 12 уроков чтения — слоги, слова, мягкость согласных, Ё, Ь и Ъ, слово и картинка, пропущенные буквы и короткие предложения.
- Управление касанием или мышью: выбор карточек, поиск букв, сборка слогов и слов по порядку.
- Вопрос повторяется нажатием на облачко. После двух ошибок появляется подсказка; неверные ответы не отнимают награды.
- В заданиях на самостоятельное чтение варианты заранее не озвучиваются. Слово звучит после ответа или по явной подсказке.
- За верный ответ с первой попытки — 2 кристалла, после ошибки — 1. За каждую новую звезду урока — ещё 5 кристаллов.
- Подарки украшают космический класс: гирлянда, голограмма, музыкальный орбитрон, робот, конфетти, салют, цветок и цвета каюты.
- Звёзды, кристаллы, покупки и настройки хранятся в `localStorage` браузера.

## Запуск

Можно открыть `index.html` как обычный файл. Для записанного голоса, скачивания звука и офлайн-режима нужен локальный или обычный HTTP(S)-сервер:

```bash
C:\TST\python.exe -m http.server 8768 --bind 127.0.0.1
```

Затем открыть `http://127.0.0.1:8768/index.html`. Нажатие на строку голоса в меню скачивает все записи на устройство.

На iPad можно добавить страницу на экран «Домой» через «Поделиться». Прогресс принадлежит адресу сайта: при открытии с другого адреса начинается отдельное сохранение.

## Голос

Озвучка записана моделью Silero, голос `aidar`, спокойный темп. Реплики учеников воспроизводятся выше. Если записи нет или она недоступна, используется русский синтез речи устройства. Строка в меню всегда показывает текущий режим.

Отдельные токены в тексте озвучки:

- `#м` — название буквы;
- `#з_м` — звук буквы, для кратких согласных — опорный слог;
- `#с_ма` — слог;
- `#3` — число словами при записи.

Модели Silero распространяются по некоммерческой лицензии CC BY-NC-SA: продавать игру с этой записанной озвучкой нельзя.

## Файлы и проверка

| Путь | Назначение |
|---|---|
| `index.html` | Вся игра, персонажи SVG, уроки, звук и сохранение |
| `voice/` | Записанные фрагменты; имя файла — хеш текста |
| `sw.js` | Открытие страницы без интернета |
| `tools/autorun.js` | Автопрогон и аудит всех уроков в браузере |
| `tools/voice_collect.py` | Сбор всех статических и динамических фраз |
| `tools/voice_build.py` | Запись новых фраз и обновление списка в HTML |
| `tools/voice_test.py` | Проверка сети, скачивания, офлайн-голоса и запасного синтеза |
| `tools/voice_stress.txt` | Поправки ударений для записи |

Автопрогон на запущенной странице:

```js
await import('/tools/autorun.js?' + Date.now());
await BOT.run();
BOT.audit();
```

Ожидаемый аудит: 45 уроков, 45 уникальных идентификаторов, 33 уникальные буквы, 12 уроков чтения и пустой список ошибок.

Перезапись голоса после изменения фраз:

```bash
C:\TST\python.exe -u tools\voice_collect.py
C:\projects\CHESS\voicekit\.venv\Scripts\python.exe -u tools\voice_build.py
C:\TST\python.exe -u tools\voice_test.py
```
